Importar dados de Excel ou CSV

As abas LISTASAQ, LISTAMAR, Matriz Geral Saquarema, Matriz Geral Maricá e Extra_Gestão são compatíveis com a estrutura de importação. Selecione a aba e a unidade correta.

Confira a prévia antes de confirmar. Em XLSX, é necessária conexão com a internet para carregar a biblioteca de leitura. CSV funciona diretamente.

Exportação Excel — modelo institucional

Gera a capa comparativa no formato dos resumos originais e as matrizes de aulas com as 13 colunas do arquivo de referência. O relatório usa os registros do navegador e respeita a unidade selecionada no topo.

Ainda não há dados históricos importados. O comparativo mostrará “Não informado” onde faltar base anterior.

A exportação não substitui nem modifica as planilhas originais. A base histórica é guardada no IndexedDB deste navegador e também no backup JSON.

Armazenamento local e backups

Os dados são gravados no IndexedDB deste navegador. Não existe sincronização entre computadores, mesmo quando a página está hospedada no GitHub Pages.

Exporte backups periódicos. Limpar os dados do navegador pode apagar os cadastros.
